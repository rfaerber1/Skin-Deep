## Skin-Deep
A react-based web app exploring the state of health equity in dermatology with features supporting experiential learning from a matching game to interactive ML models

Originally created for the 2024 Kode with Klossy x Deliotte: Health Equity Challenge 

View Live Web App: [Skin Deep: Equity in Dermatology](https://skin-deep-lf0y.onrender.com/)
